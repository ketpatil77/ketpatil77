# Security Policy

## Reporting

If you find a security issue in a public project owned by this account, please report it privately by email:

- ket.patil77@gmail.com

Please include:

- affected repository
- vulnerable file or endpoint
- reproduction steps
- potential impact
- suggested fix, if known

## Scope

This profile repository is documentation-only. Security-sensitive reports usually belong to the affected application repository.

## Public Disclosure

Please avoid publishing exploit details before the issue is reviewed and fixed.
